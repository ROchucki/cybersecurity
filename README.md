# Cybersecurity

Prywatne repozytorium do nauki cyberbezpieczeństwa, dokumentacji i narzędzi.

## Struktura

- `security/modules/` — moduły, skrypty i ćwiczenia
- `security/reports/examples/` — przykładowe raporty
- `security/reports/private/` — prywatne notatki i raporty
- `security/shared/` — wspólne zasoby
- `docs/` — dokumentacja projektu
